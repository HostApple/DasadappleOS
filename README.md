# DasadappleOS 

> A personal webOs built for Hackclub stardance evente.
> https://hostapple.github.io/DasadappleOS/

**DasadappleOS** is a browser-based desktop environment inspired by desktop operating systems(windows and linux) with minimal design. It combines a clean interface with draggable windows, useful mini-apps(spotify player , notes app , desktop clock , folder feature maps etc), and smooth animations and a cool loading screen

##  Features

-  **Desktop environment** — a clean, minimal workspace.
-  **Draggable windows** — kinda janky.
-  **Desktop clock** — a live clock and date display.
-  **Spotify player** — listen through an embedded Spotify playlist.
-  **Notes** — notes app where you can write stuff.
-  **About Me** — something about me :3 .
-  **Startup animation** — THIS IS THE BEST LOOKING PART "yO wassup" my signature text.
##  Built With
HTML,  CSS , JavaScript .
Some actions may vary depending on your browser and operating system.

##  Design Philosophy
I wanted to make a WebOs for a long time . I saw a mission on stardance hackclub and decided to do it . I started doing it thinking of doing a aero windows 7 style but that was WAY TO hard for me so I decided on a clean minimal retro "coder" text vibe webos with a really cool loading screen . I was heavily inspired by the apple loading screen so i decided to do mine like that . I did take some AI help in the code because javascript is really hand and some css bug fixes . The goal was to make a small web project feel like a thoughtfully designed operating system.

##  Notes

- Spotify playback and availability depend on Spotify and the user's account or region.
- This project is experimental and may contain bugs , im currently fixing the code and trying to make it better for WEBOS 2 .
